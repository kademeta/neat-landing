Section 01

Step-by-Step Installation

Get up and running with the NEAT pre-release builds in seconds.

1

Authorized Web Store Access

Ensure you are logged into your authorized Chrome testing Google account. Click our private invitation link to navigate to our developer pre-release invitation page on the Chrome Web Store and select "Add to Chrome".

Go to Authorized Web Store Link
2

Pin the NEAT Extension

After adding NEAT, click on the Extensions jigsaw puzzle icon in the top right corner of your Chrome browser window. Find NEAT in the list and click the Pin icon so it is always active and visible in your toolbar.

3

Access the Toolbar Popup

Click the pinned NEAT icon in your toolbar. You will be greeted by our onboarding interface where you can review your saved AI tokens dashboard, adjust models, and set custom triggers.

4

Launch ChatGPT, Claude, or Grok

Head to your generative AI interface of choice. You will see NEAT's custom control pill embedded right on top of the prompt text box field, automatically active for live context injection and secure PII masking!

Section 02

Core Features to Test

Please direct your focus toward these crucial components. High emphasis on Vibe Mode!

Priority 1 Compression Core

Vibe Mode & Prompt Compression

Vibe Mode is our signature feature. It strips verbose conversational filler words client-side to decrease context token count, saving money and increasing generation speed while keeping the core semantic prompt parameters intact.

⚡ Prime Test Prompt: Alex Rivera / PhotoFlow Copy & paste directly
"Hello! Could you please act as a senior software consultant? I really need help. Can you look at this code? My CEO, Alex Rivera, at PhotoFlow asked me to implement a fast local cache using custom middleware. Please make it extremely detailed, clean, and highly secure. Let's do this step by step. Thank you so much!"

• The Goal: Paste this prompt with Vibe Mode enabled.

• Expected Behavior: NEAT should automatically remove the conversational fluff (like "Hello", "please act", "I really need help", "Thank you so much") and compress the overall prompt length by 30-50%, while leaving critical identifiers (*senior software consultant*, *Alex Rivera*, *PhotoFlow*, *local cache*, *custom middleware*) fully intact.

Priority 2 Local Privacy Shield

PII Shield & One-Click Recovery

NEAT operates 100% locally. The security classifier automatically scans and masks passwords, emails, credentials, and API keys with a generic token (e.g. `[EMAIL_1]`) client-side before the data is transmitted to the AI provider.

Test Case 1: Redaction

Type a mock API key like sk-proj-4j1A8f... or an email address inside your prompt box. Confirm that characters are redacted immediately.

Test Case 2: Recovery Button

Locate the masked tags. Hover over the redacted block inside the NEAT toolbar element and click the Recovery Button to instantly revert specific values prior to submitting.

Priority 3 Workflows

Context Tags & Snippet Injection

Store extensive code rules, system guidelines, API definitions, or templates inside the toolbar dashboard, and inject them instantly inside Chat interfaces using keyboard triggers.

Example Trigger Test:

1. Open the popup settings tab. Add a template tag called #api-spec with a mock JSON schema context.

2. Go to your prompt text field, type #api-spec, and press space. Verify that the preset expands and injects your pre-saved JSON context instantly!

Priority 4 Analytics

Settings Panel & Real-Time Insights

Confirm that metric calculations for saved prompts accumulate correctly. Inspect variables (total tokens saved, cumulative cash value saved) in your pinned extension dashboard.
